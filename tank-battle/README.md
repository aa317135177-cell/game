# 坦克大战

网页单人版坦克大战。保护基地，消灭全部敌军。

## 运行

安装 Node.js 后，在仓库根目录执行以下命令。

```bash
cd tank-battle
npm ci
npm run dev
```

浏览器打开终端里给出的本地地址，默认是 [http://localhost:5173](http://localhost:5173)。

## 操作

- 方向键 / WASD：移动
- 鼠标左键：开火
- P：暂停
- M：静音
- 回车：开始、继续、下一关

## 当前内容

- 5 关地图：边境哨所、钢铁要塞、江心渡口、密林伏击、最终防线
- 每关敌军数量和编成不同，从 12 辆逐关增加到 20 辆
- 玩家 3 条命，火力等级跨关保留，阵亡后清零
- 砖墙可打穿，钢墙挡弹，水面不能通过，草丛会遮住坦克
- 基地被击中立刻失败

## 道具

每关第 4、8、12… 辆敌军会闪红光，打中它就会在地图上掉落一个道具，12 秒内没捡会消失。

| 道具 | 效果 |
| --- | --- |
| 星星 | 火力升 1 级：子弹更快、可同时打更多发，满级可打穿钢墙 |
| 铲子 | 基地周围的墙变成钢墙 15 秒，结束前会闪烁 |
| 炸弹 | 立刻消灭场上全部敌军 |
| 头盔 | 10 秒无敌护盾 |
| 坦克 | 生命 +1 |

## 音效

音效由浏览器 Web Audio 实时合成，不需要额外资源文件。第一次点击或按键后才会出声；按 M 或点击右侧「音效」按钮可以静音。
