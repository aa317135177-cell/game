# 坦克大战

网页单人版坦克大战。保护基地，消灭全部敌军。

## 运行

安装 Node.js 后，在仓库根目录执行以下命令。

```bash
cd tank-battle
npm ci
npm run dev
```

浏览器打开终端里给出的本地地址，默认是 [http://localhost:5173](http://localhost:5173)。

## 操作

- 方向键 / WASD：移动
- 空格 / J：开火
- P：暂停
- 回车：开始、继续、下一关

## 当前内容

- 2 关地图
- 玩家 3 条命
- 每关 12 辆敌军：普通、快速、装甲
- 砖墙可打穿，钢墙挡弹，水面不能通过
- 基地被击中立刻失败
