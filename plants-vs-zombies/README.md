# 植物保卫战（Plants vs Zombies · 网页版）

一个用原生 HTML / CSS / JavaScript + Canvas 实现的塔防小游戏，无需安装、无需构建，双击 `index.html` 即可在浏览器中游玩。

## 玩法

- **种植**：点击或拖拽顶部卡牌到草坪格子（需要足够阳光，卡牌有冷却时间）
- **阳光**：点击掉落/向日葵产出的阳光进行收集
- **铲子**：点击铲子后再点植物可移除
- **目标**：抵挡 5 波僵尸，僵尸走到最左侧会触发该行的除草机（一次性）；除草机用完后再被突破即失败
- **快捷键**：`1`–`4` 选卡 · `Esc` / 右键 取消 · `空格` 暂停

## 植物

| 植物 | 阳光 | 作用 |
|---|---|---|
| 向日葵 | 50 | 每 12 秒产出 25 阳光 |
| 豌豆射手 | 100 | 向本行发射豌豆（20 伤害 / 1.4 秒） |
| 坚果墙 | 50 | 高血量肉盾 |
| 樱桃炸弹 | 150 | 1.2 秒后炸毁 3×3 范围内僵尸 |

## 僵尸

普通僵尸（200 HP）· 路障僵尸（560 HP）· 铁桶僵尸（1300 HP）
