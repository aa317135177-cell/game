# 网页小游戏合集

每款游戏放在独立目录中。下载或克隆仓库后，按下表启动。

| 游戏 | 玩法 | 本地启动 |
| --- | --- | --- |
| [植物保卫战](./plants-vs-zombies/) | 种植植物，抵挡 5 波僵尸 | 保持 `assets/` 与 `index.html` 同目录，双击 `plants-vs-zombies/index.html` |
| [坦克大战](./tank-battle/) | 驾驶坦克，保护基地并消灭敌军 | 在 `tank-battle/` 中依次执行 `npm ci` 和 `npm run dev`，打开终端显示的地址 |
